# Security Policy

This repository contains synthetic demo transformation code only. Do not open
public issues that include real credentials, tokens, private keys, customer data,
or production infrastructure details.

Runtime project IDs, buckets, connection names, and governance groups should be
configured outside this repository through the companion demo repo `.env` and
Composer/Dataform compilation overrides.

To report a security concern about this demo, use GitHub private vulnerability
reporting if it is enabled on the repository. If private reporting is not
available, open a public issue that describes the class of issue without
including secrets, credentials, private infrastructure details, or customer data.
